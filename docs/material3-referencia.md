# Referencia para el diseño visual con Material 3

Sitio oficial: https://m3.material.io/

Usar esta guía como referencia cuando retomemos el diseño visual de la aplicación ACIS en Jetpack Compose. Revisar especialmente color y temas, tipografía, formas, componentes y accesibilidad; después adaptar esos criterios a las pantallas del flujo de órdenes de trabajo.

La aplicación usa Jetpack Compose y Material 3 (`androidx.compose.material3`). La primera mejora visual aplica roles de color, tipografía y formas al encabezado, listado, formularios y detalle de las OT. Podemos seguir usando esta guía cuando se revisen nuevas pantallas o estados.
